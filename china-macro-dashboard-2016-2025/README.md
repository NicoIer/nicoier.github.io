# 中国宏观经济指标十年趋势（2016—2025）

交互式图表已集成到博客文章 `source/_posts/中国宏观经济指标十年趋势.html`；无需新增依赖。

## 文件

- `source/_posts/中国宏观经济指标十年趋势.html`：可按分类筛选的交互式仪表板文章。
- `charts/`：18张可单独使用的SVG静态图。
- `data/china_macro_2016_2025.csv`：宽表原始数据。
- `data/data_dictionary.csv`：指标名称、单位和口径说明。
- `sources.md`：年度来源和数据限制。

## 口径提示

- 覆盖最近十个完整年度，未混入2026年不完整年度数据。
- 数据按各年度统计公报发布值录入，属于当年公报的数据版本；历史数据可能在后续经济普查或核算中修订。
- GDP增速、工业增加值增速和居民收入实际增速为实际口径；零售、投资、财政和人民币计价进出口增速通常为名义口径。
- 2016—2017年未披露与后续同口径的年末全国城镇调查失业率，因此保留为空值。
- 图表用于宏观趋势观察，不构成预测或投资建议。
